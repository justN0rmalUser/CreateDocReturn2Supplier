## Цель
Создание документа возврата товара в корпоративной системе **AutoDealer**.

### Требования
- Программа должна безошибочно считавать все данные с API поставщиков товаров (_Rossko_, _Profit-Liga_).
- Программа должна на основе считанных данных выявлять когда именно был оформлен возврат товара.
- Программа должна иметь низкий процент ошибок при поиске возвращенного товара и в случае "аномалии" - детектить и удобно представлять информацию об этом.
    - Программа должна иметь хороший уровень покрытия логами в целях выявления таких "аномалий".
- Программа должна создавать документ во внутренней корпоративной системе на основе этих данных.
- Программа должна иметь удобную и понятную структуру с четкой разграниченной ответственностью так, чтобы отдельные модули программы (микросервисы) можно было использовать в дальнейших проектах с минимальной доработкой/переработкой.

## Представление программы в виде последовательности логических блоков

- **На данный момент**:  
    - `main.py` (вход в программу)
    - `get_data.py` (получение данных и адаптация)
    - `main.py` (транспортировка данных в следующий блок)
    - `request.py` (обновление данных в fdb базе)
- **Возможная представимость**:  
    - `main.py` (вход и основной поток выполнения)
    - `fetch.py` (получение данных с сервера)
    - `main.py` (проброс значений на след. этап)
    - `adapt.py` (исследование и преобразование данных в удобный для базы данных формат)
    - `main.py` (транспортировка данных в следующий блок)
    - `update.py` (внесение корректировок в бд)
