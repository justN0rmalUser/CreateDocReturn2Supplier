`format` - модуль подпрограммы adapt, который преобразует данные в удобный формат.

## Цель
Привести данные к стандартному виду

## Структуры
### Класс ProductList
Класс, который реализует хранение и навигацию по массиву данных

#### Функция from_supplier
Функция создает массив данных исходя из API поставщика (для каждого своя)

#### Функция adapt
Функция подбирает соответствующий метод создания класса исходя из метаданных массива

#### Функция add
Конкатенация данных одного и того же поставщика

#### Контракт данных
Данные хранятся в словаре вида:
```Python
data = {
    DateKey: {
        OrderId: {
            ProductId: list 
            [
                (
                    current_status: int,
                    count: int
                    descript: str
                    (path_to_order: int, path_to_product: int): tuple, 
                    data: list[tuple[dict]]
                ), ... 
            ]
        }
    }
}
```
