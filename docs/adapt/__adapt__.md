`adapt` - пакет модулей программы, который преобразует данные в удобный формат и исследует их, чтоб выявить возвращенные.

## Цель
Привести данные к стандартному виду и найти возвраты

### Общие шаги к достижению
~~0. Понять как возможно отличить данные~~
1. Преобразование данных в формат, мат. операции с данными (_`format`_)
2. Сравнение со вчерашним случаем и нахождение данных (_`research`_)
3. Возврат готовых данных для базы (_`find`_)

### Условия и свойства
- Необходимо передать данные в формате `(SUPPLIER.NAME, SUPPLIER.ID, data)` для модуля "update.py"
- Файлы для каждого поставщика в "backup/cache/supplier" должны создаваться гарантированно
- Пустые товары не должны добавляться в результат
- Стоит перевести данные из списка в генератор и настроить совместимость с `update.py`
- Стоит унифицировать получение допустимых статусов для `supplier`
