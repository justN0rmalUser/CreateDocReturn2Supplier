`logs` - модуль подпрограммы utils, который предоставляет функции для работы с логами

## Цель
Создать модуль, который дает функции для работы с логами:
- Быстрое создание нового логгера
- Получение логгера по имени
- Ротация логов
- Очистка старых логов

## Структуры
### Класс Logger
Класс, который предоставляет такие методы и аттрибуты для логгирования разных случаев и разных уровней

### Классовая функция new
Создает логгер на основе шаблона на определенном пути

### Классовая функция get
Получает существующий логгер
