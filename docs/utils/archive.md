`archive` - модуль подпрограммы fetch, который архивирует и удаляет старые ответы серверов

## Цель
Создать модуль, который сохраняет данные сортируя по поставщику и дате (первично поставщик), а также удаляет очень старые записи.

## Структуры
### Функция `archive_raw`
Функция, которая помещает python-object ответ поставщика в файл ".../archive/supplier/date.json"

### Функция `archive_processed`
Функция, которая архивирует файл ".../archive/supplier/date.pkl"

### Функция `flush`
Функция которая чистит старые архивы (на вход дата)
