`fetch` - пакет модулей программы, который возвращает полученные данные с сервера

## Цель
Произвести запрос к API и вернуть данные после первичной обработки

### Общие шаги к достижению
1. Подпрограмма запрашивает данные с API поставщиков _(модуль: `suppliers`)_
2. Подпрограмма берет данные за определенный период (64 дня относительно вчерашнего дня для каждого запуска) _(модуль: `suppliers`)_
3. Подпрограмма возвращает этот кусок ответа
