`supplier` - тип модулей подпрограммы fetch (инъективное множество модулей для каждого поставщика), который возвращает полученные данные с запроса к этому поставщику

## Цель
Достать данные с API конкретного поставщика

## Структуры
### Класс `Supplier`
Класс, который наследует `Supplier` из `supplier_pattern` и реализует запрос и первичную обработку по количеству данных. Состоит из:
- Функции `fetch_data` запроса к серверу
- Функции `pull_data` выделения нужного количества информации из ответа (из абстрактного класса)
- Описанных в `supplier_pattern` констант 
- Дополнительных функций для получения данных (при необходимости)

### Протокол передачи данных
Данные передаются кортежем со внутренними значениями, специфичными для каждого класса
