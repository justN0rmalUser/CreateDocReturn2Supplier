`supplier_pattern` - модуль подпрограммы fetch, который задает абстрактный класс для `supplier`

## Цель
Задать абстрактный класс с последующей возможностью в `__init__` перебрать каждый класс

## Структуры
### Класс `Supplier`
Класс, который реализует запрос и первичную обработку по количеству данных. Состоит из:
- Функции `pull_data` выделения нужного количества информации из ответа
- Константы `NAME`, которая является наименованием поставщика большими буквами
- Константы `ID`, которая является ID поставщика во внутренней системе
