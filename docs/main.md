`main.py` - вход программы с функцией `run`, которая является основным потоком выполнения кода.

## Цель
Управлять потоком данных и абстрактной последовательностью исполнения кода.

## Структуры
### Функция `run`
Функция `run` выполняет запуск модулей и направляет между ними данные

### Переменная окружения с конфигом
Путь к конфигу, который загружается в окружение, позволяя иметь стандартный путь на всех путях программы
