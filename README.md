# Задачи проекта

1. Получение данных через SOAP (zeep) и сохранение в js_res.json
2. Фильтрация заказов по статусу (status) из js_res.json
3. Запись отфильтрованных данных в SQL-базу данных
4. Создание накладных на основе данных из БД для системы AutoDealer
5. (Опционально) Логирование и обработка ошибок

## Описание этапов

- **Получение данных:**
  - Использовать zeep для запроса заказов через SOAP API
  - Сохранять результат в кортеж

- **Фильтрация:**
  - Загружать json из кортежа
  - Фильтровать заказы по полю status

- **Запись в SQL БД:**
  - Создать структуру таблиц для хранения заказов и позиций
  - Записывать отфильтрованные данные в БД (FireBird)

- **Создание накладных:**
  - На основе данных из БД формировать накладные
  - Интеграция с AutoDealer для передачи/создания накладных

- **Логирование и обработка ошибок:**
  - Вести журнал ошибок и действий

## Требования
- Python 3.8+
- zeep
- fdb
- Документация по API AutoDealer
